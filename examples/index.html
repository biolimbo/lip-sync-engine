lip-sync-engine

Examples

Lip-sync animation from audio in the browser, using WebAssembly and PocketSphinx. Each example records or loads audio, analyzes it, and animates the mouth shapes in sync with playback.

What the Examples Show

Microphone recording (5 to 60 seconds)
Loading any audio file the browser can decode
Optional dialog text for better accuracy
Main thread, worker, and chunked modes
Streaming mode (React, Vue, and Svelte)
Mouth shapes animated in sync with playback
Execution time, cue count, and worker metrics
Timeline of all mouth cues
React

Run with npm install && npm run dev
